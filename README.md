# 🤖 AI Trade Guardian

AI Trade Guardian is an autonomous AI-powered crypto trading agent built for the Bitget AI × Crypto Trading Hackathon.

## 🚀 Agent Workflow

### 👀 Perception
- Reads live crypto market data
- Tracks BTC, ETH, SOL, BNB
- Calculates RSI indicators

### 🧠 Decision
- Scores trading opportunities
- Generates BUY / WAIT / AVOID signals
- Ranks best opportunities

### ⚙️ Execution
- Simulated paper trading engine
- Stores trade history

### 🛡️ Risk Management
- Position sizing
- Stop loss calculation
- Take profit targets

## Features

✅ Multi-coin scanner  
✅ Autonomous refresh  
✅ Trading dashboard  
✅ Paper trading  
✅ Risk engine  
✅ AI-style market reports  

## Tech Stack

- Python
- Streamlit
- Pandas
- Crypto market APIs

Install:

pip install -r requirements.txt

streamlit run dashboard.py
