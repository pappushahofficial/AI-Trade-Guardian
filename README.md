# 🤖 AI Trade Guardian

🚀 Built for Bitget AI Hackathon

AI Trade Guardian is an AI-powered crypto market assistant using Bitget live market data and Qwen AI intelligence.

## ✨ Features

- 🤖 Qwen AI Market Analysis
- 📈 Bitget Live Crypto Data
- 📊 RSI Technical Indicator
- ⚠️ Risk Level Detection
- 🟢 BUY / 🔴 SELL / 🟡 HOLD Signals
- 📉 Interactive Price Charts
- 🔄 Auto Market Monitoring


## 🧠 How It Works

1. Fetches live market candles from Bitget API
2. Calculates RSI indicators
3. Detects trading signals
4. Sends market context to Qwen AI
5. Generates AI-powered trading insights


## 🛠 Tech Stack

- Python
- Streamlit
- Bitget API
- Qwen AI
- Pandas
- Plotly
